## The stacking rules: what combines and what doesn't

This is where most coupon roundups go quiet, and it's the part that actually changes your total. Three rules worth knowing before checkout:

**Promo codes generally don't stack with each other.** You get one code per order. The exceptions are narrow: in physical stores you can sometimes combine a mailed paper coupon with another in-store offer, and on Black Friday stores have historically allowed one dollar-off coupon, one gift-with-purchase, and one percentage-off coupon each per transaction — though that's at manager discretion.

**Deal pricing and codes interact unpredictably.** Fixed-price deals ($4.95 shower gel, $1.95 hand cream) and B3G3 promotions often carry exclusions that block percentage codes on those items. If your 20% code suddenly only discounts half the cart, that's why.
